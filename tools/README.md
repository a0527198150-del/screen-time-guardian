# בדיקת קומפילציה בלינוקס

הקבצים כאן משמשים לבדיקת טיפוסים של הקוד בסביבה שאין בה Windows ואין גישה ל־NuGet.

`Shims.cs` — הצהרות ריקות של API של Windows (Registry, SecurityIdentifier, PipeSecurity, AddWindowsService).
`WpfShims.cs` — הצהרות ריקות של WPF, WinForms ו־OpenFileDialog.

**אלה לא חלק מהמוצר.** אין להם התנהגות; הם קיימים רק כדי שהקומפיילר יוכל לבדוק את הקוד. הבנייה האמיתית קורית ב־GitHub Actions על windows-latest.

מה הבדיקה הזו מוכיחה: אין שגיאות תחביר, אין טיפוסים חסרים, אין חתימות שלא תואמות, כל שדה שה־XAML מגדיר קיים ומשמש בטיפוס הנכון.

מה היא לא מוכיחה: שה־XAML עצמו מתקמפל, שחבילות NuGet נפתרות, ושחתימות ה־API האמיתיות זהות לחיקויים כאן.
