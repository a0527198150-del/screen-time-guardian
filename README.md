# שומר זמן מסך

פרויקט Windows לניהול זמן מסך, חסימת אתרים כלל־מחשבית וחסימת חשבון Google מסוים בתוך דפדפנים מנוהלים.

## מצב הפרויקט

זהו שלד מקור ראשון שנכתב ללא התקנות או קומפילציה מקומית, בהתאם להרשאה שניתנה. Chrome ו־Microsoft Edge זוהו כדפדפנים מותקנים; לא נמצאו דפדפנים נוספים ברשומות ההתקנה שנבדקו.

## עקרונות

- דפדפן מאושר רשאי להיפתח תמיד.
- אתרים ברשימת החסימה נאכפים לכל המחשב, ללא שינוי DNS.
- חסימת חשבון Google מתבצעת לפי החשבון הפעיל בתוסף.
- מצב Guest וגלישה פרטית מותרים רק כאשר ניתן להבטיח שהתוסף פעיל או שאין חסימה רלוונטית.
- סיסמת מנהל אינה נשמרת בקוד או בקובץ ההגדרות.

## מבנה

- `src/Guardian.Contracts` — מודלים, לוח זמנים, מנוע מדיניות ואחסון הגדרות.
- `src/Guardian.Service` — שירות Windows ורכיב אכיפת אתרים.
- `src/Guardian.NativeHost` — גשר Native Messaging עבור Chrome/Edge.
- `src/Guardian.ControlPanel` — ממשק WPF בעברית.
- `extension` — תוסף Manifest V3.
- `policies` — תבניות מדיניות ודוגמאות רישום Native Host; אינן מורצות אוטומטית.
- `docs` — תכנון, אבטחה ומגבלות.

## חשוב

החסימה ברמת הדומיין משתמשת בתשתית FQDN של Windows Firewall כמתאם ראשון. Microsoft מציינת מגבלות עבור Secure DNS, Proxy, VPN וכתובות שמורות במטמון. לפני הפעלה בסביבת נטפרי יש לבצע בדיקת תאימות, ואין להריץ את סקריפטי המדיניות ללא אישור מנהל ובדיקה.
