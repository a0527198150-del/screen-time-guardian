# מדריך פריסה מבוקרת

## מצב נוכחי

הפרויקט מוכן ליצירת חבילת פריסה ב־GitHub Actions. לא בוצעה התקנה במחשב המקומי.

## יצירת חבילה

1. להיכנס ללשונית Actions במאגר הפרטי.
2. להפעיל ידנית את Workflow בשם `package`, או ליצור תגית גרסה כמו `v0.1.0`.
3. להוריד את החבילה מתוך Artifacts.
4. לאמת את מקור החבילה ואת טביעת הקובץ לפני שימוש.

## סדר התקנה עתידי

1. ליצור נקודת שחזור וחשבון מנהל זמין.
2. לבנות או להוריד חבילה מאומתת.
3. לפתוח PowerShell כמנהל.
4. להריץ את `Install-Service.ps1` עם נתיב השירות בלבד.
5. לפתוח את לוח הניהול מחשבון מנהל.
6. לגלות את Chrome ו־Edge ולאשר רק את הדפדפנים הרצויים.
7. לרשום את Native Host באמצעות `Register-NativeHost.ps1` לאחר שקיים מזהה תוסף סופי.
8. להחיל את מדיניות Chrome/Edge רק לאחר בדיקת התוסף.
9. להתחיל ב־`AuditOnly` עבור חסימת אתרים.
10. לבצע בדיקת אתר אחד בלבד מול נטפרי.
11. רק לאחר הצלחה לעבור ל־`Enforced`.

## שחזור

- להסרת השירות בלי למחוק הגדרות: `Uninstall-Service.ps1`.
- למחיקת ההגדרות יש להשתמש במפורש ב־`-RemoveData`.
- במקרה של כלל שגוי, יש להשתמש בחשבון המנהל לפני ניסיון נוסף.

## מה עדיין דורש בדיקה חיה

- זיהוי חשבון Google בתוך Gmail ו־Chat.
- טעינת התוסף בחלון פרטי.
- התנהגות Guest לאחר שינוי מדיניות.
- חסימת דומיין מול נטפרי.
- חתימת חבילת הפריסה ועדכון אוטומטי.
