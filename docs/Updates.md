# עדכונים ושמירת נתונים

- קובצי התוכנה נמצאים בתיקיית ההתקנה.
- ההגדרות נמצאות ב־`C:\ProgramData\ScreenTimeGuardian`.
- עדכון אינו אמור למחוק את לוח הזמנים, האתרים, החשבונות או הדפדפנים המאושרים.
- `SchemaVersion` מאפשר להוסיף שדות בלי לאבד הגדרות ישנות.
- לפני שמירת תצורה קיימת נוצר קובץ גיבוי `.bak`.
- מנגנון העדכון האוטומטי קיים אך כבוי כברירת מחדל.
- הפעלה דורשת כתובת manifest ב־HTTPS, מפתח ציבורי RSA, חתימה תקינה ו־SHA-256 תואם.
- ה־Service וה־Updater מאמתים את החתימה; ה־Updater מאמת שוב את ה־hash לפני עצירת השירות.
- Redirect אוטומטי חסום, כדי שכתובת HTTPS לא תוביל בשקט למקור HTTP.
- `Guardian.Updater` בודק נתיבי ZIP נגד חילוץ מחוץ לתיקיית staging, מנקה קבצים ישנים לפני החלפה, ומבצע rollback רק לאחר שנוצר גיבוי מלא ואם השירות אינו חוזר.

אין להפעיל עדכון אוטומטי ממקור שאינו בשליטת המנהל.
