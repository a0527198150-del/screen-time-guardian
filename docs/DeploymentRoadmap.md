# מפת הדרך לפריסה

הקוד מחולק לשכבות, אך הפעלה אמיתית דורשת שלבים שאי אפשר לבצע בבטחה ללא קומפילציה ובדיקות:

1. קומפילציה ב־GitHub Actions או במחשב פיתוח.
2. חתימה על קובצי ההרצה ועל התוסף.
3. פריסת התוסף במקור מנוהל וקבלת מזהה תוסף סופי.
4. רישום Native Host עבור Chrome ו־Edge.
5. יצירת חשבון מנהל נפרד והתקנת השירות בהרשאת Administrator.
6. יצירת הרשאות NTFS עבור ProgramData.
7. יצירת כללי AppLocker/App Control לדפדפנים מאושרים בלבד.
8. בדיקת Guest ו־Incognito במצב ללא חסימה ובמצב חסימה.
9. בדיקת `AuditOnly` מול נטפרי.
10. מעבר ל־`Enforced` רק לאחר אישור שהאתרים החסומים אינם שוברים את הגלישה האחרת.

אין לפרוס את הסקריפטים בתיקיית `policies` לפני גיבוי ודרך שחזור עם חשבון מנהל.
