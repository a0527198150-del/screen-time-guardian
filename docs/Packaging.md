# חבילת הפריסה

ה־Workflow של החבילה יוצר חבילת התקנה מלאה לגרסת 0.4.5, הכוללת את רכיבי התוכנה ואת סקריפטי ההתקנה:

- שירות Windows;
- לוח ניהול WPF;
- Native Host עבור Chrome ו־Edge;
- Updater.

בנוסף נארזים:

- תיקיית התוסף;
- סקריפטי המדיניות;
- תיעוד הפריסה;
- סקריפטי `Install-Service.ps1`, `Uninstall-Service.ps1`, `Emergency-Disable.ps1` ורישום ה־Native Host.

החבילה אינה כוללת הגדרות אישיות, כתובות חשבון, סיסמאות או קובץ `ProgramData`.

## לוחות זמנים והשהיה

לכל חלון זמן יש `activationDelaySeconds`. הערך נשמר בתצורה ונאכף בשירות עצמו, כך שסגירת לוח הבקרה אינה משנה את ההתנהגות. `0` הוא ברירת המחדל ומפעיל חסימה מיד עם תחילת החלון. הארכת ההשהיה נחשבת הקלה ועוברת דרך זמן הצינון אם הוא גדול מאפס.

הגדרות המשתמש נשארות מחוץ לתיקיית ההתקנה, ולכן עדכון מחליף תוכנה בלבד. מנגנון העדכון האוטומטי מושבת עד להטמעת חתימה דיגיטלית ואימות מפתח ציבורי בתוך הבינארי. אין להפעיל אותו ידנית.
