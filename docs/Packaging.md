# חבילת הפריסה

ה־Workflow של החבילה יוצר ארבעה רכיבי תוכנה:

- שירות Windows;
- לוח ניהול WPF;
- Native Host עבור Chrome ו־Edge;
- Updater.

בנוסף נארזים:

- תיקיית התוסף;
- סקריפטי המדיניות;
- תיעוד הפריסה.

החבילה אינה כוללת הגדרות אישיות, כתובות חשבון, סיסמאות או קובץ `ProgramData`.

הגדרות המשתמש נשארות מחוץ לתיקיית ההתקנה, ולכן עדכון מחליף תוכנה בלבד. לפני שימוש אמיתי יש להוסיף חתימה דיגיטלית לחבילות, להטמיע אימות מפתח ציבורי, ולשמור עותק שחזור.
