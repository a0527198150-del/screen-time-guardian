# מדיניות חסימת כתובות בדפדפן

כאשר `BlockUrlsInManagedBrowsers` מופעל, השירות כותב את רשימת האתרים הפעילה למדיניות הארגונית של Chrome ושל Edge:

- `HKLM\SOFTWARE\Policies\Google\Chrome\URLBlocklist`
- `HKLM\SOFTWARE\Policies\Microsoft\Edge\URLBlocklist`

כל ערך הוא מחרוזת ממוספרת (`1`, `2`, `3` וכו׳). דומיין כמו `example.com` חוסם גם את `www.example.com` ואת כל תתי־הדומיינים שלו. השירות מנרמל את הדומיינים ומסנן ערכים שאינם דומיין תקין; תבנית `*` אינה מתקבלת.

המדיניות נפרדת מחסימת האתרים דרך Windows Firewall, ולכן אפשר להפעיל מנגנון אחד בלי השני. Chrome ו־Edge קוראים את המדיניות לפני ניווט חדש, והמדיניות חלה על כל חשבונות המחשב. Firefox אינו מכוסה במנגנון הזה.

בכל מחזור מדיניות תת־המפתח נכתב מחדש. כך דומיין שהוסר אינו נשאר כערך ישן כאשר הרשימה מתקצרת. כשל כתיבה אינו נשמר כהצלחה, והמחזור הבא ינסה שוב.

בעת עצירה נקייה של השירות או הסרת התוכנה, `URLBlocklist` נמחק בשני הנתיבים כדי לא להשאיר את הדפדפן חסום לאחר שהשירות אינו פעיל.
