# מצב נוכחי

## בוצע

- נוצר מאגר GitHub פרטי בשם `screen-time-guardian`.
- זוהו Chrome ו־Microsoft Edge כדפדפנים מותקנים.
- נוצרה תצורת Solution עם פרויקטי Contracts, Service, Native Host ו־WPF Control Panel.
- נוצר תוסף Manifest V3 עם זיהוי חשבון Google והודעות Native Messaging.
- נוצרו תבניות מדיניות Chrome/Edge ותיעוד App Control.
- נוצר Workflow שמאפשר קומפילציה מרוחקת ב־GitHub Actions.

## לא בוצע

- לא הותקן שום רכיב במחשב.
- לא שונתה מדיניות Windows, חומת האש, DNS, נטפרי או הרישום.
- לא נרשם שירות Windows.
- לא נרשם Native Host.
- לא קומפל הקוד מקומית.
- לא נבדקה חסימת אתר בפועל.
- לא נבדק זיהוי חשבון Google בדפדפן חי.

## מגבלה ידועה

הפריסה המנוהלת של תוסף MV3 דורשת מזהה תוסף סופי ומקור עדכון מתאים. הקוד הנוכחי מכיל placeholder עד שהפריסה תוגדר.
