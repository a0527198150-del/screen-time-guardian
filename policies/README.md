# מדיניות התקנה

הסקריפטים בתיקייה זו הם מקור בלבד. הם לא הורצו.

## סדר התקנה עתידי

1. לבנות ולחתום את השירות, ה־Native Host והתוסף במכונת פיתוח.
2. לפרסם את התוסף במקור התקנה מנוהל או להשתמש בשרת עדכונים פנימי.
3. להחליף את `EXTENSION_ID_PLACEHOLDER` במזהה התוסף הסופי.
4. להריץ את הסקריפטים מתוך חלון PowerShell כמנהל.
5. להגדיר AppLocker או App Control/WDAC כדי לאפשר רק דפדפנים חתומים ומאושרים.
6. לבדוק Guest, Incognito, פרופילים חדשים ועדכוני דפדפן.
7. רק לאחר בדיקה מול נטפרי לשנות את חסימת האתרים מ־`AuditOnly` ל־`Enforced`.

## אזהרה

`ExtensionSettings` עם `force_installed` דורש תוסף שמופץ באופן שמתאים למדיניות הדפדפן. תיקיית מקור מקומית אינה תחליף לפריסה מנוהלת. אין להכניס סיסמת מנהל לסקריפטים.

מדיניות Chrome/Edge נטענת לעיתים רק בהפעלה מחדש. לכן שינוי Guest בזמן ריצה עשוי לדרוש סגירה ופתיחה של הדפדפן.
